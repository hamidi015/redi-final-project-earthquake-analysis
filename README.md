# ReDI School – Final Project: Global Earthquake Analysis

This repository contains my final project for the ReDI School Data Analytics course.

The project analyzes global earthquake data from 1965–2015 using Python and Tableau.  
It includes data cleaning, exploratory data analysis, visualizations, and an interactive Tableau dashboard.
